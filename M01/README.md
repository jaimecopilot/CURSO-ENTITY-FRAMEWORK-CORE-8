# Módulo 1 — Fundamentos de Entity Framework Core

Este módulo desarrolla los puntos 1.1 a 1.12 mediante teoría y práctica separadas sobre el proyecto acumulativo **AceriaData**, utilizando .NET 8, Entity Framework Core 8 y SQL Server LocalDB.

## Recorrido

1.1 ORM y EF Core → 1.2 arquitectura → 1.3 componentes y migraciones → 1.4 DbContext → 1.5 ciclo de vida → 1.6 DbSet y CRUD → 1.7 Change Tracker → 1.8 gestión de entidades → 1.9 SaveChanges y unidad de trabajo → 1.10 configuración y logging → 1.11 proveedores con práctica sobre SQL Server → 1.12 inyección de dependencias y AddDbContext.

## Resultado del módulo

Al finalizar M1, AceriaData contiene `OrdenFabricacion`, `PlanchaAcero`, `Aleacion` y `EstadoOrden`, migraciones acumulativas, configuración externa, logging, repositorio, servicio de negocio e inyección de dependencias sobre SQL Server LocalDB.
